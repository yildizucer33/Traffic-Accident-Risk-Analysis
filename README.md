#  Traffic Accident Severity & Pattern Mining

Data mining and machine learning project analyzing municipal traffic accident datasets in Turkey to uncover risk factors and predict severity levels.

##  Highlights
- **Exploratory Data Analysis & Preprocessing:** Handled missing values, outliers, and categorical encoding on historical accident records.
- **Unsupervised Pattern Mining:** Clustered accident-prone locations using K-Means and extracted frequent condition patterns with the Apriori algorithm.
- **Predictive Modeling:** Built and evaluated Decision Tree, Naive Bayes, and SVM models to classify fatal/injury risks.

##   Tech Stack
- Python (Jupyter Notebook)
- Pandas, NumPy, Scikit-learn
- Matplotlib, Seaborn
